# Retail Package

Auto-generated Laravel package by ME Utility.

## Installation

```bash
composer require mestiaque/retail
```

## Usage

After installing the package, the service provider will be auto-discovered by Laravel.

### Routes

- Web: `/retail`
- API: `/api/retail`

### Views

```php
view('retail::index');
```

### Translations

```php
trans('retail::message.welcome');
```

### Config

Publish the config file:

```bash
php artisan vendor:publish --tag=retail-config
```
